# 숲이 된 도시 — 작은 생존자의 일기

지브리풍 포스트 아포칼립스 로그라이크 생존 게임 (HTML5 Canvas, 설치/빌드 불필요).

## 실행
- **가장 간단히**: `index.html` 더블클릭
- **로컬 서버로**: `게임실행.bat` 더블클릭 → http://localhost:8765 (같은 와이파이의 폰 테스트 시에는 별도 서버 필요)

## 조작
| 동작 | 키보드 | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 드래그 |
| 대시(무적) | Space | 💨 버튼 |
| 거점 관리 | E (거점 안에서) | 🏕️ 버튼 |
| 일시정지 | Esc / P | ⏸ 버튼 |
| 카드 선택 | 1 · 2 · 3 | 터치 |

## 게임 구조
- **낮**: 나무·폐차·덤불·결정 광맥 옆에 서면 자동 채집 → 거점 건물 발전
- **밤**: 검은 안개 괴물 웨이브, 자동 공격(뱀서라이크). 5일마다 보스
- **목표**: 생명나무를 5단계까지 키우면 승리 (이후 무한 모드)
- **캐릭터 7명** (모두 처음부터 선택 가능, 각자 시작 무기·특성이 다름): 민지 · 두산 · 영민 · 성우 · 훈 · 대희 · 민용
- **로그라이트**: 죽어도 🌱기억의 씨앗으로 영구 강화
- **난이도**: 쉬움 / 보통 / 어려움 / 매우 어려움 / 하드코어(영구강화 미적용·건설 중 시간 흐름·보상 3배)

## 파일
- `js/data.js` — 밸런스 수치 전부 (난이도, 건물, 스킬, 적, 이벤트). 수치 조정은 여기서
- `js/art.js` — 모든 그림 (코드로 그리는 절차적 아트, 이미지 파일 없음)
- `js/game.js` — 게임 로직·렌더 / `js/ui.js` — 메뉴·HUD / `js/audio.js` — 합성 사운드·BGM
- `tools/bot.js` — 밸런스 점검용 자동 플레이 봇 (콘솔에서 `runBot('normal', 16)`)
