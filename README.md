# 숲이 된 도시 — 작은 생존자의 일기

지브리풍 포스트 아포칼립스 **자유 건설 생존** 게임 (HTML5 Canvas, 설치/빌드 불필요).
플레이: https://bds100.github.io/forest-city-survivor/

## 실행
- `index.html` 더블클릭, 또는 `게임실행.bat` → http://localhost:8765

## 조작
| 동작 | 키보드·마우스 | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 드래그 |
| 공격 (도구 휘두르기) | Space / 마우스 클릭 | ⚔️ 버튼 |
| 대시(무적) | Shift | 💨 버튼 |
| 건설 메뉴 / 핫바 | B / 1~6 → 마우스로 위치, 클릭으로 설치 (드래그로 연속 설치) | 핫바 터치 → [설치] |
| 철거 | X | 🧹 |
| 상호작용 (작업대·주민·침대·생명나무·구조) | E | 화면의 노란 버튼 |
| 일시정지 | Esc / P | ⏸ |

## 게임 구조
- **건설**: 48px 격자에 벽·문·바닥·침대·텃밭·작업대·횃불·울타리·함정·포탑을 자유 배치. **벽과 문으로 빈틈없이 둘러싼 방 안에 침대**가 있으면 집으로 인식되어 지붕이 덮임
- **낮**: 자원 옆에 서면 자동 채집 / **밤**: 괴물이 생명나무와 플레이어를 향해 직진하며 막는 건물을 부숨 → 벽·함정·포탑으로 방어, 직접 도구로 전투
- **주민**: 매일 아침 폐허에서 구조 신호 → 찾아가 E. 빈 침대가 있는 집이 있어야 입주. 벌목/고철/농사/경비 일을 하며 매일 식량 2 소비. 친구 7명(민지·두산·영민·성우·훈·대희·민용) 중 고른 1명 외 6명이 주민 후보
- **목표**: 생명나무를 에테르 결정으로 5단계까지 키우면 승리 (이후 무한 모드)
- **저장**: 자동 저장(30초·매일 새벽·일시정지), 타이틀의 이어하기. 쓰러지면 자원 30% 잃고 모닥불에서 부활(하드코어는 종료), 생명나무가 쓰러지면 종료
- **난이도** 5단계, 🌱기억의 씨앗으로 영구 강화

## 파일
- `js/data.js` — 밸런스 수치 (난이도, 건축물 `G.STRUCT`, 도구, 적, 이벤트, 캐릭터·눈 좌표)
- `js/art.js` — 코드로 그리는 배경·건축물·적 + 이미지 캐릭터의 Live2D식 메시 애니메이션
- `js/game.js` — 건설·방 판정·전투·주민 AI(A* 길찾기)·저장·렌더 / `js/ui.js` — 메뉴·HUD / `js/audio.js` — 합성 사운드·BGM
- `assets/chars/*.png` — 캐릭터 이미지 (교체 시 `tools/cutout.ps1` 로 배경 제거, `data.js` 의 EYES 좌표 재측정)
